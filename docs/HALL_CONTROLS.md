# Большой холл

В Visual Studio выбери `simple_castle.exe` и запусти проект. При запуске открывается новый холл. Если окно программы уже открыто, закрой его перед повторной сборкой — Windows не позволяет перезаписывать работающий exe.

| Клавиша | Действие |
|---|---|
| A / D | Идти влево / вправо; камера плавно следует за рыцарем |
| Левый Shift | Быстрее пройти длинный зал |
| W / S | Приблизить / отдалить камеру |

| C (латинская) | Показать ближнюю сторону зала / снова сделать разрез |
| Home | Вернуть обычный масштаб, высоту камеры и разрез |
| F1 / F2 | Фасад / холл |
| Esc | Закрыть программу |
| P | Параллакс вкл / выкл |
| G | Плёночный вид (пост-обработка) вкл / выкл |
| J / L | Повернуть свет |
| I / K | Поднять / опустить свет |
| Q | Качество POM: Low / Medium / High |

| H | Подсказка по клавишам на экране |

| B | Отсечение задних граней вкл / выкл (выкл — задние стороны красные) |

| E | Взять ключ / открыть ворота / войти в сад / вернуться из сада в холл |
| F3 | Сразу в сад (без квеста). В саду A / D ведут камеру по дорожке |

По умолчанию виден разрез: ближние стена, колоннада, галерея и половина свода скрыты. Это позволяет видеть проход с боковой камеры. Полная модель содержит две симметричные стороны, по 12 колонн на каждой. Радиус ствола — 4,9 м; высота колонн — 44 м.

Рыцарь — тёмный рыцарь высотой около 1,75 м (`darkKnight()`): чернёные латы, закрытый шлем, рваный плащ с красной подкладкой, меч. Тот же рыцарь в заставке нарисован плоской фигурой в `shaders/intro.frag`. Он перемещается по X, на центральной дорожке Z = 0. Перед тронными ступенями движение заканчивается; прыжки и подъём по ступеням пока не реализованы.

## Где разбирать код

- `src/hall_geometry.h`: размеры зала, число колонн и параметры размещения.
- `src/hall_geometry.cpp`: `column`, `portal`, `sideWall`, `vault`, `arcade`, `hangingBanner`, `crystalChandelier`, `throne`, `brazier`, `darkKnight` и сборка в `Hall::build`.
- `shaders/hall.frag`: POM на стенах (`parallaxUV`, `parallaxShadow`), материалы камня, ткани, ковра, металла; холодный и тёплый свет, дымка.
- `src/main.cpp`: управление, камера, переключение фасад / холл, кадр по шагам.
- `src/hud.cpp`, `shaders/text.*`: текст на экране и подсказка по H.
- `src/post.cpp`, `shaders/post.*`: HDR-кадр и пост-обработка (G).
- `src/dust.cpp`, `shaders/dust.*`: пыль в воздухе (1200 точек).
- `src/intro.cpp`, `shaders/intro.*`: заставка с кнопкой START.
- `src/garden_*.cpp`, `shaders/garden*`: внутренний сад за воротами.

Номера материалов в `enum Material` (`hall_geometry.h`) и в константах `hall.frag` должны совпадать. Новые материалы добавляем только в конец списка, после `Blade` (24 и дальше).

Геометрия фасада остаётся в `src/castle_geometry.cpp`. Старый вариант внутреннего зала заменён новым модулем.

## Следующие совместные шаги

Готово: POM с картой высот, normal map и самозатенением, текст на экране, пауза, отсечение задних граней.

Готово также: свободная камера (Tab) и квест — ключ у трона, ворота, внутренний сад (E).

Готово также: зал в стиле dark fantasy, пыль в воздухе, замер скорости, заставка, сад и тёмный рыцарь.

Осталось: отчёт и видео. Текущие лучи — стилизованные прозрачные поверхности; настоящих падающих теней пока нет. Текстуры и декор можно заменять, не меняя размещение колонн.

### Отсечение задних граней

Лицевая сторона треугольника — та, с которой его вершины идут против часовой стрелки. Нормаль в `triangle()` считается из того же порядка. Зеркальные копии (`half`, `side`, торцы ±108 м) переворачивают порядок, поэтому в `portal()`, `vault()` и `arcade()` у `quad()` есть флаг `flip`. Обе стороны рисуются только у прозрачных лучей, у ближней половины зала в режиме C (на неё смотрим снаружи) и у текста.

## Проверка

Из корня проекта в Developer PowerShell for VS:

```powershell
cmake --build --preset windows-debug --parallel 4
.\out\build\windows-debug\bin\simple_castle.exe --smoke-test
```

Проверка скрыто рисует холл в разрезе, полную колоннаду, фасад и сад (заставку пропускает), проверяет ошибки OpenGL и завершает программу. Для сохранения одиннадцати контрольных видов (8 — холл и фасад, 3 — сад):

```powershell
.\out\build\windows-debug\bin\simple_castle.exe --capture-dir out\hall-review
```

Снимки PPM сохраняются из настоящего OpenGL-кадра. Они не являются нарисованными концептами.

## Замер скорости

Замер делаем в Release: в Debug программа упирается в процессор, и разница между настройками POM не видна.

```powershell
cmake --preset windows-release
cmake --build --preset windows-release
.\out\build\windows-release\bin\simple_castle.exe --benchmark
```

Программа открывает окно 1280×720 (VSync off), сама показывает 3 вида (вход, центр, трон) с POM off / Low / Medium / High, на каждый: 30 кадров разогрева и 300 кадров замера с `glFinish`, затем печатает таблицу Markdown для отчёта и закрывается.
