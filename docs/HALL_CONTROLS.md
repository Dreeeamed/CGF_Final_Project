# Большой холл

В Visual Studio выбери `simple_castle.exe` и запусти проект. При запуске открывается новый холл. Если окно программы уже открыто, закрой его перед повторной сборкой — Windows не позволяет перезаписывать работающий exe.

| Клавиша | Действие |
|---|---|
| A / D | Идти влево / вправо; камера плавно следует за рыцарем |
| Левый Shift | Быстрее пройти длинный зал |
| W / S | Приблизить / отдалить камеру |
| ↑ / ↓ | Посмотреть выше / ниже |
| O (латинская) | Общий вид всего зала / обычная камера |
| C (латинская) | Показать ближнюю сторону зала / снова сделать разрез |
| Home | Вернуть обычный масштаб, высоту камеры и разрез |
| F1 / F2 | Фасад / холл |
| Esc | Закрыть программу |
| P | Параллакс вкл / выкл |
По умолчанию виден разрез: ближние стена, колоннада, галерея и половина свода скрыты. Это позволяет видеть проход с боковой камеры. Полная модель содержит две симметричные стороны, по 12 колонн на каждой. Радиус ствола — 4,9 м; высота колонн — 44 м.

Рыцарь пока — простая движущаяся модель высотой 1,5 м для проверки масштаба. Он перемещается по X, на центральной дорожке Z = 0. Перед тронными ступенями движение заканчивается; прыжки и подъём по ступеням пока не реализованы.

## Где разбирать код

- `src/hall_geometry.h`: размеры зала, число колонн и параметры размещения.
- `src/hall_geometry.cpp`: `column`, `portal`, `sideWall`, `roof`, `chandelier`, `throne` и сборка в `Hall::build`.
- `shaders/hall.frag`: отдельные материалы камня, ткани, ковра, металла; холодный и тёплый свет, дымка.
- `src/main.cpp`: управление, камера и переключение фасад / холл.

Геометрия фасада остаётся в `src/castle_geometry.cpp`. Старый вариант внутреннего зала заменён новым модулем.

## Следующие совместные шаги

Пользователь снова пишет небольшие изменения сам. Холл остаётся нашей основной частью; фасад предварительно могут взять товарищи. На следующие этапы записаны пять более детальных люстр вместо одной и лунный свет.

После оценки пропорций разбираем и дорабатываем по одному элементу. Отдельно предстоят открывание ворот и переход по приближению рыцаря, полноценный персонаж, POM с картой высот и самозатенением. Текущие лучи — стилизованные прозрачные поверхности; настоящих падающих теней пока нет. Текстуры и декор можно заменять, не меняя размещение колонн.

## Проверка

Из корня проекта в Developer PowerShell for VS:

```powershell
cmake --build --preset windows-debug --parallel 4
.\out\build\windows-debug\bin\simple_castle.exe --smoke-test
```

Проверка скрыто рисует холл в разрезе, полную колоннаду и фасад, проверяет ошибки OpenGL и завершает программу. Для сохранения шести контрольных видов:

```powershell
.\out\build\windows-debug\bin\simple_castle.exe --capture-dir out\hall-review
```

Снимки PPM сохраняются из настоящего OpenGL-кадра. Они не являются нарисованными концептами.
