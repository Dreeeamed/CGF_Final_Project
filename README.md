# CGF_Final_Project

**Topic 15: 2.5D castle with parallax occlusion on walls**
Срок отправки: **17 ноября 2026, 23:59** (Moodle, Final Project Reports).

## Что уже есть и что осталось

| Требование задания | Статус |
| --- | --- |
| 2.5D-замок, который можно исследовать | Большой холл (60 × 40 × 216 м, 24 колонны) и фасад со стрельчатым входом |
| Фасад с ощущением интерьера | Через арку фасада виден зал с колоннами |
| Parallax occlusion mapping на стенах | Готово: послойный ray march в tangent space, интерполяция между слоями, число слоёв по углу взгляда (`shaders/hall.frag`, `parallaxUV`) |
| Карта высот для POM | `assets/textures/stone_wall/height.png`, `textureGrad` с производными вне цикла |
| Normal mapping вместе с POM | Готово: `normal.png` читается в смещённой точке |
| Боковой свет и самозатенение POM | Готово: мягкие тени от рельефа (`parallaxShadow`), свет двигается J/L/I/K |
| Переключатели P (POM), Q (качество), пауза, текст на экране и подсказка H | Готово |
| Отсечение задних граней | Готово: `GL_CULL_FACE`, отладочный вид на B (задние стороны красные) |
| Свободная камера | Готово: Tab |
| Взаимодействие (ключ / знамя / ворота) | Готово: ключ у трона (E), ворота с поднимающейся решёткой, вход во внутренний сад; игрок — тёмный рыцарь (латы, рваный плащ, меч) |
| Пост-обработка | Готово: HDR-кадр (framebuffer, MSAA 4x), свечение (bloom через мипмапы), ACES, сплит-тон, виньетка, зерно; G вкл / выкл |
| Заставка | Готово: замок вдали, слои пейзажа с параллаксом от мыши, рыцарь на тропе, кнопка START (клик или Enter); после START рыцарь идёт к воротам |
| Внутренний сад | Готово: за воротами — фонтан с водой из частиц, деревья, клумбы, кусты, скамейки, фонари; F3 — сразу в сад |
| Зал в стиле dark fantasy | Готово: колонны из чёрного мрамора с золотом, стрельчатый свод с рёбрами, аркада со стенами в POM, знамёна с гербом, 5 хрустальных люстр с тёплым светом, трон на 12 мраморных ступенях, магические жаровни и магический круг, гигантские знамёна |

Атмосфера: холодный лунный свет и тёплые хрустальные люстры, туман по глубине, лучи из окон, пылинки в воздухе (1200 точек GL_POINTS).
Направление сцены — в `docs/SCENE_DIRECTION.md`, подробности холла и
управление — в `docs/HALL_CONTROLS.md`.

## Первый запуск в Visual Studio

1. Нужна Visual Studio с компонентами **«Разработка классических приложений
   на C++»** и **«Средства CMake C++ для Windows»**. Нужны CMake 3.24 или новее
   и видеодрайвер с поддержкой OpenGL 3.3.
2. Клонируй репозиторий и открой его папку через **File → Open → Folder**.
   Открывать нужно папку, в которой находятся `CMakeLists.txt` и
   `CMakePresets.json`.
3. Выбери конфигурацию **windows-debug / Windows x64 Debug**. Если после
   добавления presets она ещё не появилась, закрой и снова открой папку.
4. Дождись завершения настройки CMake. При первой настройке CMake скачает
   GLFW и GLM с GitHub; нужен интернет. GLAD уже включён в исходники.
5. Выбери цель запуска **simple_castle.exe** и нажми **Ctrl+F5**.

Вручную прописывать include-пути, подключать `.lib` или устанавливать vcpkg
для этого проекта не нужно. `windows-release` предназначен для сборки
с оптимизацией; сначала используем Debug.

## Управление

Программа начинается с заставки: мышь слегка двигает камеру, кнопка START
(клик или Enter) отправляет рыцаря к воротам, Enter во время пути пропускает его.
Затем открывается холл у входных ворот: торцевая стена видна под скользящим
углом, и рельеф POM заметен с первых секунд.

| Клавиша | Действие |
| --- | --- |
| A / D | Рыцарь идёт влево / вправо (в холле и в саду), камера следует за ним |
| Левый Shift | Идти быстрее |
| W / S | Холл: приблизить / отдалить камеру. Сад: камера движется по дуге вверх / вниз вокруг точки, на которую смотрит |
| ↑ / ↓ | Камера прямо вверх / вниз |
| O | Общий вид всего холла или всего сада |
| C | Показать ближнюю сторону холла / вернуть разрез |
| Home | Сбросить камеру (холла или сада) |
| Escape | Выход |
| P | Параллакс вкл / выкл |
| G | Плёночный вид (пост-обработка) вкл / выкл |
| J / L | Повернуть свет (в саду — луну) |
| I / K | Поднять / опустить свет (в саду — луну) |
| Q | Качество POM: Low / Medium / High |
| V | VSync вкл / выкл |
| M | Музыка вкл / выкл |
| H | Подсказка по клавишам на экране |
| Space | Пауза анимации: частицы, вода, огонь |
| B | Отсечение задних граней вкл / выкл (выкл — задние стороны красные) |
| Tab | Свободная камера в холле и в саду (P и Q работают и в ней): W/S/A/D — полёт, R/F — вверх/вниз, стрелки или правая кнопка мыши — взгляд |
| E | Взять ключ / открыть ворота / войти в сад / вернуться в холл у двери в стене сада |
| F3 | Сразу в сад (без квеста) |

## Сборка из командной строки

В **Developer PowerShell for Visual Studio** перейди в корень репозитория:

```powershell
cmake --preset windows-debug
cmake --build --preset windows-debug
```

Готовая программа: `out/build/windows-debug/bin/simple_castle.exe`.
Папки `shaders` и `assets` автоматически копируются рядом с программой при
сборке, в том числе если изменились только шейдеры. Запускай программу из
корня проекта или из папки `bin`, где находятся эти ресурсы.

Короткая проверка окна, OpenGL, шейдеров и отрисовки четырёх кадров
(холл, полная колоннада, фасад, сад; заставка пропускается):

```powershell
./out/build/windows-debug/bin/simple_castle.exe --smoke-test
```

Эта проверка создаёт скрытое окно и завершается сама. Успех — сообщение
`Smoke test passed: 4 frames rendered.` и код возврата 0.

## Как работаем втроём

- `main` — общая проверенная версия.
- На каждую задачу создаём отдельную ветку, например `feature/pom-walls`,
  `feature/castle-scene` или `feature/key-and-gate`.
- Перед новой задачей получаем свежую версию `main` через Pull.
- После изменения: сохранить файлы → Commit → Push → Pull Request в `main`.
- Перед объединением другой участник проверяет изменения и запуск.
- `out`, `build`, `.vs` и личные настройки IDE исключены из Git.

Актуальная проверенная версия — в `main`. Перед работой сделай в Visual Studio
Fetch и Pull.
